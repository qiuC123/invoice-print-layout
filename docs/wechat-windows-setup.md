# Windows微信读取适配器设置

本仓库提供消息解析、归属和持久化适配器，不包含外部微信读取工具、账号数据库、密钥或完整的常驻收发服务。克隆本仓库并不表示已能读取微信。

## 配置要求

1. 自行准备与当前微信版本兼容的读取工具，核验其来源、帮助及实际输出契约，见 [读取接口](wechat-reader.md)。
2. 使用独立的私有运行目录，向适配器传入读取工具的绝对路径及 `runtime_dir`。该目录需已有工具要求的配置；不要在公开源码目录保存本地数据库密钥。
3. 只绑定已核实的当前账号、群或私聊稳定ID。显示名不能替代身份校验；多账号不能共用未核验的守护进程。
4. 先验证指定测试会话的方向、发送者、时间和完整性，再接入业务。历史记录可查询不代表实时接收正常。

外部读取工具可能按工作目录查找 `config.json`，初始化可能生成账号配置及数据库密钥。相关文件始终留在私有目录，不提交、不上传。切换运行目录不等于实现多账号隔离。

## 当前边界

- 微信4.1.15.12的本机兼容测试尚未完成，持续采集和真实收件箱接入未验收。
- 本项目未实现微信消息发送接口，也没有默认启用自动催问或每日调度。
- 需要电脑开机、联网并持续接收消息；休眠、微信升级、同秒消息、引用与崩溃恢复均需单独验证。
- 读取故障不能直接归因为系统权限不足；应先核对版本和工具日志，不反复提权或盲目扫描。

私有调试记录与构建缓存不随源码发布。原型、单元测试或界面展示不等于微信端到端联通。
