# 固定模板卸货日报

工作台“现场照片 → 生成卸货日报”：填写报告/运输日期、当天连续施工时段和此前已确认累计工时，匹配车头照片，核对固定内容后生成。预览展示本机 PowerPoint 实际导出的页面，下载保留可编辑 PPTX。

当前模板为两辆车卸货日报，每车各一张工厂车头、现场车头。工厂照片允许早于进场日期，以项目、车牌和运输日期关联；现场照片必须摄于报告当天。只使用已保存记录，名称需明确标注“车头”。候选不唯一时手选；缺图、车辆数量不符、图片损坏或生成期间改动分类时停止交付。分类正确不等于已经收集到全部车辆，生成前仍需核对配图。

前三页、施工内容、明日计划和版式锁定。可修改内容限定为日期、搭建第几天、当日时间、当日/累计小时、照片及车牌图注。明日计划的时间及内容保持原模板。当前只支持同一天的连续时段，不推断休息时长、加班或前几日出勤。

## 模板与运行数据

每个项目独立配置于 `workspace/现场进度/<project_id>/日报/模板/`：

- `template.pptx`：已确认且能在 PowerPoint 正常打开的固定模板。
- `template.json`：模板 SHA-256、首个搭建日、默认时段、固定内容说明、页数、照片页、文字锚点与照片关系。
- `text_fields` 以 XML 部件、文本 run 索引、原值和允许替换字段为锚点；原值不符立即停止。
- `slots` 指定原照片关系 ID、原图注及工厂/现场，按车辆成对排列。

这些文件和生成报告包含项目资料，保留在忽略的 workspace，不提交代码。新模板需先验证文字锚点、图片槽位和原生 PowerPoint；不能将某份卸货模板自动套用到其他施工内容或结算报告。

结果保存在同项目 `日报/结果/<id>/`。回执记录模板/成品/图片校验值、分类版本、工时和 PowerPoint 检查结果。只有正常打开、页数/照片数及所有预览页齐全后才开放预览/下载；失败结果不在历史中显示。文件下载再次验证项目归属和校验值。

## 兼容性与边界

运行需要 Windows 和已安装的 Microsoft PowerPoint。只读打开生成文件，导出预览，不保存原模板，也不关闭用户的其他演示文稿。全机进程内原生渲染串行，单次最长150秒。

采用原 PPT 包内局部替换，不重新绘制前三页，不复制图形私有标签。复制形状时复用 tags 关系曾导致 PowerPoint 修复后照片丢失，不能只凭通用 PPT 渲染器通过便认定兼容。

这一入口由用户手动生成；未连接每日自动报告或飞书发送。既有定时照片整理保持原行为。后续安装日报、展期/撤展日报及结算报告需要各自确认模板与配图规则。
