# 手机与电脑同一 Wi-Fi 联通

电脑保存唯一账本并执行材料识别、组合、核对及报表服务。手机使用浏览器操作同一账本，不需要安装独立发票 APK，也不需要导入或同步两份账本。

手机不在同一网络时，使用 [Tailscale 私人异地访问](phone-remote.md)，在电脑版同一「手机连接」入口切换连接方式。

## 使用

1. 电脑照常运行根目录的「打开发票助手.cmd」。
2. 手机和电脑连接同一 Wi-Fi。在电脑版右上角点击「手机连接」。
3. 选择实际连接 Wi-Fi 的网络地址，点击「开启手机连接」。用手机扫一扫打开二维码，建议使用手机浏览器打开。
4. 手机选择已有项目，点「上传材料 → 从相册多选」，勾选多张照片后确认。PDF 或图片可用「选择文件（PDF／图片）」；在文件列表长按第一份，再勾选其余文件。支持 PDF、JPG、PNG、WebP，每份最多 20MB，每批最多 50 份。
5. 材料原件保存在电脑；电脑只对本份材料执行本地 PDF 解析或 OCR。检查原件、修正识别结果。建议组合须人工确认；没有合适建议时可手选材料组合。
6. 确认报销项目、金额和费用归属人，创建待核对费用。进入「待核对」查看原件，再明确点击核对完成。电脑刷新即可在「可提交」看到相同费用，继续制作报销表和打印包。

电脑修改费用后，手机点击「刷新」或重新打开网页即可看到结果。费用修改和核对带版本检查；如果电脑已更新，手机旧页面的保存会被拒绝，刷新后再操作。结果不明的写入不会自动重发，应先刷新核对。

## 连接状态

- 默认只允许本机访问。只有在电脑主动开启后，才在选定的本机私有 IPv4 地址监听 TCP 8767。没有配置公网、路由器端口映射或云端服务。
- 二维码有效 10 分钟。更新二维码会废止旧二维码，已配对手机继续可用；手机配对会话最长 12 小时。
- 电脑点击「关闭手机连接」会使所有手机会话失效并关闭监听。退出或重启电脑助手也会关闭连接；下次需要重新开启并扫码。
- 电脑和助手需要保持运行。当前不支持电脑关机后的独立处理或离线缓存待上传。
- 网页只开放材料、原件和费用核对。人员名单管理、项目管理、报销表及打印包制作继续在电脑完成。
- 手机连接固定使用电脑本地识别，不受桌面云端识别设置影响；不会自动领取二维码中的网络发票链接。原件保持不变。

## 手机打不开时

确认两端连接同一个 Wi-Fi，并使用本次生成的二维码。访客网络或路由器的设备隔离可能阻止互访。电脑切换网络后，关闭并重新开启连接，选择新的 Wi-Fi 地址。只有数字地址、不带扫码配对信息的链接不能完成首次配对。

若 Windows 防火墙阻挡，允许这份助手所使用的 Python 程序在当前局域网访问 TCP 8767；不要关闭防火墙或把端口映射到公网。路由器隔离及实体手机厂商浏览器需在对应设备上验证。

## 开发验证

后端回归：`python -m pytest tests/test_phone_link.py`。页面回归：安装项目既有 Playwright 依赖后运行 `node tests/phone_web_browser.cjs`。完整项目交付仍需完整 pytest 和 mypy。

模拟器应通过电脑实际的局域网地址访问，不使用 `adb reverse` 代替网络联通。二维码图像可解码校验其内容，再让安卓浏览器打开同一地址；这不等同于实体手机相机的实拍扫码验收。
