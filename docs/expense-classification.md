# 费用分类建议

在待提交事项详情中点击“建议费用分类”。先保存商品说明或用途备注；系统本地读取购买凭证、订单和发票，明确收费名采用固定规则，其余明确商品文字可交给 Jev 判断。

用户已于2026-09-24批准本范围的云端分类与真实样例验证。仅此按钮触发，不在打开页面、上传凭证或定时后台时自动发送。原始PDF、图片不会上传；不发送金额字段、订单号字段、项目名、商家字段、文件名或整张发票文字。发送筛选后的商品/服务文字和用途备注，过滤带联系信息的行及长编号；自由备注请仅填写与费用用途有关的内容。界面可展开查看用于判断的文字。

结果是建议，不自动保存或核对。点击“采用建议（未保存）”只填入分类下拉框，随后“保存事项”才通过现有接口保存。材料要求、核对与提交仍由原流程处理。选择类别不能替代公司的报销制度。

固定类别：材料采购、酒店、高铁、外卖、打车、顺丰、其他。货运尚无专门规则，不能误归打车；混合费用、笼统日用百货及信息不足时保留人工判断。Jev置信度低于0.8不提供可采用类别，此阈值是保守运行设置，不是经校准的准确率。接口超时、无凭据、非法返回均不改账；期间事项变化或前端修改会使旧建议失效。

## 接口与凭据

- `POST /api/category/suggest`，请求只有已保存事项的`id`，沿用本机Host/Origin/token校验，仅接受待提交事项。
- `GET /api/state`中的`category_suggestion_ready`表示后端支持入口；旧服务不显示按钮。
- 使用已有`TYPESAFE_API_KEY`或`JEV_API_KEY`环境变量，或`~/.config/ai-secrets/typesafe.env`。不得记录密钥值。
- 固定API `https://api.typesafe.ai/v1/systemone`，模型`jev-1.13.0`，Choice类型，超时20秒、禁止重定向。不把模型输出作为代码、命令或自由写入操作。
- 模型提供类别选择；说明由固定类别定义及本地提取文字组成，不伪称模型生成了自由文字推理。[官方Choice说明](https://docs.typesafe.ai/primitives/choice)

## 验证

真实雨衣、口罩案例是本轮开发验证材料，曾用于调整类别说明，不能称为独立盲测。私有结果保存在`workspace/expense-classifier-evidence/`，不提交真实票据或文字。额外合成样例在`tests/fixtures/expense_categories.json`，不能代表所有陌生发票的准确率。单元测试与浏览器测试覆盖不写台账、分类边界、模型异常、未保存表单、异步切换、转义和手机布局。
