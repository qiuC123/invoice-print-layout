# 手机异地访问电脑版

手机和电脑登录同一个 Tailscale 私人网络，手机浏览器操作电脑保存的唯一账本。手机无需安装发票助手 APK，不需要迁移或同步账本。电脑需要保持开机并运行助手。

## 电脑端

1. 首次准备：在项目目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-phone-remote.ps1`。脚本从官方源获取有签名的 Windows x64 组件，只解包到私有 workspace，不安装系统 VPN 驱动或机器服务。
2. 照常运行「打开发票助手.cmd」，右上角「手机连接」选择「异地访问 · Tailscale」。
3. 点击「连接私人网络」，在登录链接中用自己的账号绑定 `invoice-desktop`。可把登录链接发给自己在手机打开；无需把密码或认证密钥交给助手。
4. 登录完成后「刷新连接状态」，点击「开启异地访问」。页面显示私人地址、二维码和「复制手机配对链接」。
5. 关闭手机连接会撤销所有配对、关闭本机入口，并移除私人 HTTP 转发。重新打开助手后需再次开启；网络账号保留，不会每次重新注册电脑。

## Android 手机

1. 从 [Tailscale 官方 Android 安装说明](https://tailscale.com/docs/install/android) 安装客户端。
2. 用与电脑绑定时相同的账号登录，按 Android 提示允许建立 VPN 连接，保持 Tailscale 为已连接。
3. 在手机浏览器打开电脑生成的完整配对链接，或扫描本次二维码。首次只有不带配对信息的数字地址或普通网址不能配对。
4. 选择已有项目，点「上传材料 → 从相册多选」勾选多张照片。PDF 或相册仅能单选时，用「选择文件（PDF／图片）」，长按第一份再勾选其余文件。查看原件、修正金额及报销项目、确认组合，再明确核对完成。电脑版刷新会看到同一笔费用，可继续生成报销表与打印包。

无需连接同一 Wi-Fi；手机可以使用移动数据。设备地址以本次电脑版显示为准，不能继续使用以前的 `192.168.*` 局域网链接。二维码和配对链接有效 10 分钟；配对会话最长 12 小时。更新二维码会废止旧链接，已有会话继续可用。

## 实现与验证边界

该功能显式开启后，专用 Tailscale 节点以用户态运行，使用私人 Serve 的 HTTP 80 转发到 `127.0.0.1:8768`。HTTP 位于 Tailscale 加密隧道内；未启用公开 Funnel，没有路由器端口映射。系统上原有 VPN、DNS 和路由不改动。同 Wi-Fi 模式仍使用选定局域网地址的 8767 端口，两种模式不能同时开启。

Windows 专用节点使用无人值守模式保持已登录，避免登录命令结束后设备立即断线。手机入口仍须在助手内主动开启；退出助手会关闭入口、撤销会话并移除转发。

异地入口只开放现有手机材料和核对接口，不转发完整的电脑版管理页面。配对、独立手机令牌、来源检查、写入版本检查与本地识别规则继续有效。原件、识别和账本都在电脑。人员管理、报表与打印包在电脑完成。

自动回归：`python -m pytest tests/test_phone_link.py tests/test_phone_remote.py`；页面：`node tests/phone_link_browser.cjs`、`node tests/phone_web_browser.cjs`。本机代理回归与实体手机异地实测应分别记录；账号未登录或尚未通过实体手机连接时，不能称为完整异地验收通过。
