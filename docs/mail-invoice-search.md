# 按事项查找邮箱发票

在报销工作台选择一笔待提交事项，点击材料夹上方的“查找对应发票”。默认按邮件收件日期查最近31天，可修改开始和结束日期；最长366天，每次至多检查范围内最新300封邮件，超出时明确提示缩小范围。

系统只读检查已配置的163邮箱，不标记已读、不删除或发送邮件。取得文件后显示邮件主题、发件人、日期、匹配线索和预览入口。订单号、商家、金额只用于候选排序；同金额不等于同一费用。用户预览后选择材料用途，点击“关联到此事项”并确认。关联不会核对费用或提交报销；材料变化会回到待核对。

## 可处理的来源

- 邮件PDF/PNG/JPG/WebP附件，以及有界ZIP内的这些文件。
- 淘宝邮件的HTTPS阿里云文件直链。
- 发票通 `www.fapiao.com` 的PDF下载地址及已验证的下载跳转路径；每次跳转都重新校验，不跟随任意跳转。
- 邮件内嵌data/CID二维码，本机OpenCV解析后显示本地二维码及领取入口。没有直接下载地址、需要登录或过期时提示打开原邮件领取，取得文件后手工上传到当前事项。

不抓取远程广告图片，不执行邮件HTML或JavaScript，不绕过登录与验证码。陌生领票站点保留人工领取提示。二维码仅是领取入口，不能关联为发票。图片不会通过云端OCR解析；未找到匹配依据时保留“未发现明确匹配线索”。

## 存储和关联

候选原件、来源和查询结果保存在私有 `workspace/工作台/发票查找/<search_id>/`，查找时不写费用台账。确认关联仅操作本次查询绑定的事项；跨事项、已提交、查询后金额/项目/商家/订单号改变、文件内容变化均阻止关联。相同文件已经关联本事项时幂等返回，已被其他事项使用则提示核对重复费用。保留原始PDF，不重新生成或裁剪。

原来的“补收邮件”仍是全局PDF附件补收入口，保持原有游标规则；新的按事项查找不移动该游标，可独立回查历史邮件。

## 验证范围

合成测试覆盖只读查询、直接链接及受控跳转、PDF/图片真实性检查、ZIP边界、二维码解码、同文件去重、手动关联、跨事项与过期候选、HTTP token/文件预览，以及浏览器日期选择、确认/取消、异常提示、文本转义与手机宽度。
